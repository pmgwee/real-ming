# Real-Ming Dashboard Discovery Scope

The dashboard is the CEO's authenticated monitoring, visualization, Approval, and recovery console. Telegram remains the primary command surface.

## CEO and work operations

- CEO Overview
- Master Tasks and all Executive Work Views
- pending Approvals and artifact-bound controls
- Outcome Reports
- Executive status and blockers
- Project Portfolio
- audit history

## MicroSaaS operations center

### Knowledge health

- per-Trust-Domain last successful ingest, compile, publish, and lint time;
- candidate backlog, quarantined conflicts, stale pages, failed citations, and current generation identity;
- Knowledge Compiler and Obsidian projection health without exposing raw note content in global search or logs;
- Hermes Hot Runtime Memory write requests and Approval status, but never the memory payload on summary surfaces;
- Agent Brain evidence health remains a separate project-scoped signal rather than being merged into a universal memory status.

### GitHub Repository Center

- repository and production-branch identity;
- open task branches, pull requests, reviews, and checks;
- exact commit associated with each Deployment Candidate;
- release and incident links.

### Git state and lineage

- branch head and ahead/behind state;
- commit lineage, tags, and deployment association;
- dirty or divergent local-worker state when the private worker is online.

### Vercel deployments

- previews, production deployments, status, domain, commit, and environment;
- verification evidence and rollback candidate;
- `Approve Promotion` for one verified Deployment Candidate, never an arbitrary `Deploy latest` control.

### Metered API, model, and cloud usage

- provider-specific usage, rate-limit, error, and Metered Platform Cost adapters;
- project, provider, model, and period breakdowns where the provider exposes them;
- source and `as of` time on every cost value, with stale/unavailable-data indicators;
- the RM250 monthly global cap plus CEO-approved provider and project budgets;
- paid agent-tool plans, subscriptions, and recurring bills are excluded because DuitSini owns them;
- agent operational health may be shown elsewhere, but agent-tool subscription cost is not duplicated here.

### Scheduler and recurring-job monitoring

- inventory of Vercel Cron, GitHub Actions schedules, application schedulers, and later-authorized providers;
- expected cadence, last Scheduler Heartbeat, last success, next expected run, duration, and failure count;
- responsible Executive Role and linked run evidence;
- one missed or failed critical heartbeat triggers a Telegram Exception Notice;
- routine jobs alert after two consecutive failures;
- recovery produces one notice and repeated identical errors are grouped;
- noncritical history stays in the dashboard and evening Executive Roll-Up.

## Privacy boundary

Dashboard summaries are Approved Projections by default. Raw personal documents, messages, academic files, career files, or financial worksheets require an authorized drill-down and never enter global search or dashboard logs.

## Open inventory

- exact API, LLM, cloud, and scheduler providers per Portfolio Project;
- provider-specific availability and granularity of usage and billing APIs.
