03 · Final memory migration pipeline

1 · Candidate Envelope

Selected source content plus source ID, hash, captured / as-of time, Trust Domain, sensitivity, role visibility and retention.

many Sources of Record → provenance-bearing candidates
→

2 · Validate / Quarantine

Verify authority and freshness; reject Sensitive Secrets; detect duplicates, stale facts and conflicts; quarantine uncertain inputs.

no chat dump · no silent promotion · no uncited fact
→

3 · Knowledge Compiler

Hermes reconciles evidence, extracts claims, creates summaries and concepts, adds citations / Wikilinks, updates indexes and lints.

Karpathy-style LLM Wiki compilation
→

4 · Atomic Versioned Publish

Publish a new encrypted Markdown generation, preserve its predecessor, append the change log and release only policy-approved projections.

rebuildable knowledge · minimum context · on-demand lookup

Existing Agent Brain

Canonical append-only SQLite Project Evidence → cited versioned memories → generated project Markdown. It stays a separate project-history system, not universal personal memory.

→

Evidence Broker

Knowledge Compiler

04 · What the CEO receives

Bounded work in; review-ready outcomes out.

Daily Operations Loop

  1. Reconcile Master Tasks + Calendar
  2. Route role work and exceptions
  3. Deliver morning brief + evening roll-up
  4. File cited daily notes as candidates

MicroSaaS Operations Loop

  1. Create task branch from latest main
  2. Implement, test and push branch
  3. Open draft PR + Vercel preview
  4. CEO approves exact production artifact

Memory Quality Loop

  1. Ingest provenance-bearing candidates
  2. Compile, cite, link and reconcile
  3. Lint conflicts, staleness and islands
  4. Publish / rollback versioned generations

CEO Outcome Report

  1. Intent and completed work
  2. Evidence, effects and verification
  3. Approval / exception status
  4. Next decision or recommended action
NO money movement or brokerage trading · NO academic submission · NO direct production push / deploy-latest · NO Sensitive Secrets in model context · NO raw cross-domain memory · NO direct rewrite of Sources of Record or Agent Brain
