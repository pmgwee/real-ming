Not every message becomes a task. Hermes can answer directly, ask a clarifying question, research, or propose substantial work. A Work Item appears only when it adds useful continuity or execution state.

03Hermes

Coordinate

05Hermes

Digest results, research, code, test, diagnose and request the next operation until complete.

Answer

Compose the final response. Real-Ming delivers it and stores evidence, status and audit events.

Real-Ming owns operations

Deterministic services that personalize, connect, persist and make Hermes visible.

connects · records · observes · gates
  • TransportReliable Telegram ingress, delivery, identity and idempotency.
  • ContinuityCanonical Work Items, roles, dependencies, state and outcomes.
  • Personal contextProvider adapters, ELT, projections and cited evidence.

Hard boundaryReal-Ming does not invent a technical plan, write the feature, choose the next reasoning step or scrape actions out of Hermes’s final prose. It validates structured requests and makes them operational.

CEO acceptance test

Governance stays proportional: invisible for ordinary conversation and routine local work; explicit only where the real-world effect deserves Ming’s attention.

“I talk to one capable Hermes agent. Real-Ming quietly gives it my context, tools, continuity and a live operational memory.”

That is the product test for V5. If the user experiences a fixed router, competing personas or constant approval friction, the implementation has violated the architecture—even if every service is technically online.

Automatic by default: questions, summaries, research, drafting, local code edits and tests.
Ask when consequential: destructive changes, external messages, financial effects, production push/merge/deploy.
Preserve source truth: provider systems and Agent Brain remain authoritative in their scopes.
Keep secrets out: OAuth credentials and detected sensitive values never enter Hermes model context or dashboard events.
Make work recoverable: durable state, exact revisions, evidence and off-host backup support restart and audit.
