# Use one executive work lifecycle

Every Executive Role will manage Work Items through Captured, Triaged, Planned, Awaiting Approval, Executing, Waiting/Blocked, Verifying, Ready for CEO Review, Completed, Changes Requested, and Cancelled states. Existing `Done` records map to Completed, while ambiguous `Pending` and `To Do` records require reconciliation. A shared lifecycle was chosen so the CEO can review and audit all departments consistently without erasing their different tools and workflows.
