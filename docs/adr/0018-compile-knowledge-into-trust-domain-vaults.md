# Compile persistent knowledge into Trust-Domain vaults

Real-Ming will use Hermes as the conversational, tool, scheduling, and Knowledge Compiler runtime while storing persistent Compiled Knowledge in an encrypted, versioned, Obsidian-compatible Knowledge Vault. The vault follows the LLM Wiki method: immutable Candidate Envelopes or source pointers, LLM-owned cited Markdown, schema files, `index.md`, append-only `log.md`, ingest, query, and lint operations. Its roots are isolated by the Personal, Ming Creatives, Academic, Entertainment, and Finance Trust Domains, with a separate CEO root containing only Approved Projections; Executive Roles receive task-scoped views and never direct universal filesystem access.

Domain providers remain Sources of Record, Agent Brain remains canonical Project Evidence behind the Evidence Broker, and Obsidian remains a human-facing IDE over Markdown rather than the database or policy boundary. Hermes native `MEMORY.md` and `USER.md` are Hot Runtime Memory only and require write Approval. The Knowledge Compiler may publish a new version of derived wiki pages but may not rewrite domain records, canonical Agent Brain evidence, or Agent Brain-generated projections. Raw payloads follow domain retention rules; append-only provenance, hashes, tombstones, and purge evidence preserve explainability without keeping every sensitive payload forever.
