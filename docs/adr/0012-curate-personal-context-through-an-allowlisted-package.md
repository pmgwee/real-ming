# Curate personal context through an allowlisted package

Real-Ming will ingest personal files and selected Notion exports through a CEO-curated Personal Context Package with a manifest recording provenance, freshness, sensitivity, and permitted Executive Roles. Version control holds schemas, policies, and redacted projections; raw staging files remain outside Git, while the selected context required by always-on agents is stored in an encrypted Context Vault. V1 refreshes are manual and later Notion synchronization is limited to allowlisted page identifiers; stale context is labelled rather than silently treated as current. The package is an explicit ingestion boundary rather than a second Source of Record, copied documents are marked as snapshots, and Sensitive Secrets are excluded.
