# Use hybrid always-on execution

Real-Ming must remain reachable while Ming's Lenovo is asleep or powered off, so an isolated always-on environment will handle remote interaction, schedules, cloud APIs, and cloud-accessible work while the Lenovo acts as an on-demand private worker. Work requiring local-only files, existing local browser sessions, Windows-only tools, or the laptop's hardware must wait for that worker to return online unless it is deliberately moved to another trusted environment.
