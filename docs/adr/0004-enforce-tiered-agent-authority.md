# Enforce tiered agent authority

Agents may observe and draft automatically, and may perform bounded reversible actions under Standing Authority, but external communications, production changes, destructive operations, purchases, Money Movement, and permission changes require Approval. Each Approval is bound to one exact artifact or action and becomes invalid if that target changes. Financial Record Changes may update DuitSini metadata or create a new Financial Snapshot version when specifically authorized, but no Executive Role may initiate payments, transfers, or trades. Project agents may create and push task branches and produce preview deployments, while merging into the production branch remains a CEO-approved action; agents and models never receive Sensitive Secrets.
