# Converge tasks on one Work Item model

Real-Ming will converge `(IP Content Creation) Task To Do List`, `(MicroSaaS) Task To Do List`, `(Academic) Task To Do List`, `(Job x Life) Task To Do List`, and `(Finance) Task To Do List` on Master Tasks while preserving familiar page-level Work Views. The CEO receives an all-work view; Personal Life and Career Job route to the COO, Finance to the Personal CFO, Academic to the CAO, MicroSaaS to the CTO, and Content Creation to the CMO. Every Work Item has exactly one Accountable Executive and may have multiple Collaborating Executives. Migration will back up the five sources, create the canonical schema, import and normalize records, reconcile every active item with the CEO, and then replace daily use of the old databases with linked views. The old databases become archived evidence rather than parallel writable sources.
